# Dry run before the first real meeting (15 minutes)

Do this once with **real phones on the real network** (the venue Wi-Fi if possible, and mobile data) a few days before the meeting. Everything so far was tested on simulated devices; this checks your actual phones and network.

**You need:** 4 people (or 4 devices), the app link **https://npfernando.github.io/toastmasters-speechcraft/**, and a laptop for the Coordinator.

| Who | Device | Role(s) to pick |
|---|---|---|
| A | Laptop | 🗂 Coordinator |
| B | Phone | ⏱ Timer |
| C | Phone | 🔢 Ah-Counter **+** 💬 Table Topics Evaluator (tick both) |
| D | Phone | 🎙 Speaker (and later 🎤 Table Topics Master) |

Tick each box as you go. If something fails, use **⋯ More → 💬 Report a problem or idea** on that device, and paste the **Connection check** results into it.

---

## 1. Open and install (3 min)

- [ ] Everyone opens the link. The start screen shows **① Join the meeting**.
- [ ] On each phone: **⋯ More → 📲 Install as an app** (Android/Chrome), or Safari **Share → Add to Home Screen** (iPhone). Open it from the home-screen icon.

## 2. Connect (3 min)

- [ ] **A** taps **Host meeting & get code**. A code and QR appear.
- [ ] **B, C, D** scan the QR with the phone camera (or type the code). Each phone moves on to **② Who are you?** by itself.
- [ ] Each person picks their role(s) and taps **Start**.
- [ ] On **A**, the connection button shows **4 online**, with everyone's name.
- [ ] On **every** device: **⋯ More → 🔌 Connection check** shows **✅ Ready**.
  - ❌ *Connection relays 0 reachable* → the network blocks them; try mobile data and tell the organisers which network.
  - ⚠️ *Round trip* over 1500 ms → updates will lag on that network.

## 3. Set up as the Coordinator (3 min)

- [ ] **A** goes to the Coordinator screen, sets a PIN (note the recovery code), taps **🩺 Ready for the meeting? → 🧪 Start a dry run** (every device shows a test banner), adds the 4 names as members on **👥 People**, and on **⚙️ Set-up** sets **B** as Timer, **C** as Ah-Counter and Table Topics Evaluator, **D** as a prepared speaker.
- [ ] On **C**: Home → **Change name or role** → tapping their name pre-ticks both roles.
- [ ] **A** taps **📄 Print agenda**: one page, correct names.

## 4. Run a mini meeting (4 min)

- [ ] **D** (Speaker) enters a speech title and sets a **feedback PIN**.
- [ ] **B** (Timer) starts **D**. **D**'s phone shows the big clock. **C**'s phone shows **🔗 Speaking now: D** on both roles.
- [ ] **B** taps **⏸ Pause** for 5 seconds, then **▶ Resume**. Everyone sees *Paused*.
- [ ] **C** taps a few filler words on the Ah-Counter tab.
- [ ] Let it reach **green** (set the Prepared Speech green to 0:20 on **B** for the test). **B**'s phone **vibrates** (Android); **D**'s screen turns green.
- [ ] Lock **B**'s phone for 20 seconds and unlock: the timer is still running and correct.
- [ ] **B** stops the timer.
- [ ] **D** adds 🎤 Table Topics Master (**＋ Role**), adds two topics and calls **A** as the speaker. On **C**, **A** appears under **⭐ Your Table Topics speakers** (C is the only Table Topics Evaluator, so every speaker is shared to C).
- [ ] **C** writes a short evaluation for **A** and taps **Submit**. **A** sets a feedback PIN (Participant role) and reads it.

## 5. Finish and keep the record (2 min)

- [ ] **A** opens **🏁 After** and taps **🏁 Finish meeting**. Each phone gets the finish prompt; everyone taps **Yes, done**. **A** sees every role as ✓ Complete.
- [ ] **A** taps **⤓ Save meeting record** and keeps the file.
- [ ] **D** opens **My feedback card**, unlocks with their PIN, and sees their time and Ah-Counter count. **A** (with ＋ Role → 🙋 Participant) unlocks theirs and reads C's Table Topics evaluation; nobody else can.
- [ ] **A**: ⚙️ Set-up → **✓ Finish dry run & clean up**. Every device drops the test data; role players and the agenda stay for the real meeting. (Phones used only for testing: **About → Reset device**.)
- [ ] **A**: check **🩺 Ready for the meeting?** shows the remaining items, and use **📋 Copy reminders** to post the role list in the group chat.

---

## Brief everyone on the day

- **Keep the app open** on the Timer's phone during the meeting. iPhones pause web pages in the background; the screen stays awake while a speaker is being timed.
- **Each device keeps its own copy.** The Coordinator saves the meeting record every week (🏁 End of meeting).
- **PINs are a lock against accidental changes, not strong security.** Speaker feedback *is* properly encrypted.
- If a phone drops off, reopen the app: it reconnects to the same meeting and catches up.
- New Speechcrafters: **🎓 Practice meeting** and **📘 Role guides** (⋯ More) before their first role.
