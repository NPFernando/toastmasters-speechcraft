# General Evaluator observations

The General Evaluator view now records a meeting checklist in addition to the existing report summaries and free-text commendations/recommendations.

- Sections: preparation, opening, Round Robin, speaking sessions, evaluation and closing.
- Each item: Not observed (default), Yes, Partly, No or Not applicable, plus evidence/suggestions.
- Scheduled/actual start and end are manually entered; no punctuality judgment is inferred from speaker timers.
- Round Robin: agreed format and per-participant previous speaker's last word, opening word and manually assessed compliance. The Timer queue supplies names, not verified speaking order. These fields support the club's last-word format without changing the Round Robin Master's existing common-question workflow.
- A priority recommendation helps prepare the oral report.
- Copy and print reports include recorded observations. Existing good/improve notes remain compatible.

Observations use the existing shared `genotes` meeting state, autosave, synchronization, export and reset behavior. They are visible meeting data, not encrypted private speech evaluations. GE checklist fields now merge independently across updated devices. Same-field conflicts use timestamps and a deterministic tie-break; see MEETING-WORKFLOWS.md. Agenda-linked observations and persistent follow-up actions are also available. There is no speech recognition or automatic word comparison.

- Project reference: Speechcraft-General-Roles-and-Program-Reference-2.md (provided with this task).

The checklist is an adaptation, not a required universal meeting sequence. Opening formalities and optional sessions are evaluated against the day's agreed agenda. The last-word rule is a local format, not a requirement for every Toastmasters club.
