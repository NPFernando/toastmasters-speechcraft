How to use
Pick your roleWhen you open the page, choose your role (Timer, Table Topics Master, Ah-Counter or Grammarian), type your name, then host or join the meeting. Your device then shows only your role. Use Change role at the top if you need to switch.
Connect devicesOne person (usually the Timer) taps Not connected → Host meeting and reads out the 6-character code. Everyone else opens the page, picks their role and types the code (or opens the host's invite link, which fills the code in). Everything then syncs live. Needs internet; the link between devices is encrypted. If someone's connection drops, they keep working and catch up automatically.
Timer: plan speakersType names and press + Add to list (several at once with commas). Press ▶ Start next: Name when they stand up. Rename, reorder ↑ ↓ or remove ✕ any time.
Timer: timingType a name (optional) and press Start speaker. Add or fix the name in the live bar while they speak. Press Stop when done. The live bar flashes SHOW GREEN / AMBER / RED at each signal. If someone is still running when you start another, the page asks first.
Timer: fix or add a time✎ Add time manually for anyone you forgot. Click a finished time to correct it (m:ss). Finished speakers can't be restarted; ✕ removes them (with Undo).
Status meaningUnder time: stopped before green. Qualified: green to red inclusive. Overtime: past red. Round Robin: Within time up to the bell.
Table Topics MasterPaste topics (one per line) and press Add topics. During the session tap 🎲 Random topic or Pick on any topic, then 📺 Show on screen to display it large. Type who takes it and press ▶ Call speaker: the topic moves to Used with their name, and when connected they appear in the Timer's Table Topics list as Next up.
Ah-CounterAdd speakers (or tap + Add next to whoever is speaking now). Select a speaker and tap a word each time you hear it; − undoes one. Edit the word list under Words to count.
GrammarianEnter the Word of the Day. Select a speaker, tap +1 Word of the Day each time they use it, and note great phrases and slips.
ReportMeeting report builds one report. Tick which roles to include, then Print / Save as PDF.
Backup & new meetingData is saved on this device. ⤓ Save backup downloads a file you can ⤒ Restore anywhere. New meeting clears speakers, topics and counts (for connected devices too) but keeps names, time limits and word lists.
